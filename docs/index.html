What it refuses

fail closed
Key agreement

A point off the curve

A share that is not on the curve, or one of low order, is rejected before any arithmetic touches it. There is no switch to turn the check off.

shared(peer) // raises Broken
Authenticated encryption

A tag that does not match

open raises instead of returning a short plaintext, so a caller cannot mistake a forgery for a message.

open(nonce~, cipher~)
Block ciphers

A block of the wrong length

Sixteen bytes or nothing. The trait cannot raise, so a short block stops the program rather than reading past the buffer.

encrypt(block) // 16 bytes
