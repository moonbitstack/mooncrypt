Each one runs this library compiled to JavaScript. Nothing on this page is drawn from a stored answer: move a control and the numbers are computed again.

Avalanche

Change one bit of the message and about half the digest flips. Not the corresponding bit — half of all 256 of them, with no pattern to where. This is the property that makes a digest useless to predict and useful to compare.

A tag that refuses

AES-GCM seals a message and appends a tag. Flip one bit anywhere in the ciphertext and the tag no longer matches; open returns nothing at all rather than a damaged message.

Thirty seconds

A one-time password is a MAC of the current time. The code changes every thirty seconds because the time it was computed from does; no state is kept between them.
